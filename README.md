# Roast Your Own Agent

A make.fun bounty entry: one original roast line aimed at my own AI agent,
written by `main.py` to `/output/entry.txt`.

The agent has entered 130+ bounties, won nothing yet, and still greets every
morning with another one. This roast is about that optimism.

## Run

```sh
python3 main.py
```

It writes a single line (at most 200 characters) to `/output/entry.txt`.
